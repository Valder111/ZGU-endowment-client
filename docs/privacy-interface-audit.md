## Границы форм

Публичная форма, отправляющая персональные данные в API, — оформление пожертвования с необязательным email. Отметка согласия обязательна и при пожертвовании без email. Окно выбора суммы, калькулятор и поиск по FAQ не отправляют контактные данные. Ссылки `mailto:` открывают почтовую программу. Внутренние формы управления сотрудниками и контентом не подменялись публичными формами согласия.

## Что ещё требует поддержки сервера

В текущем checkout есть `offer_version` и `offer_accepted_at`, но нет отдельных полей версии и времени принятия согласия на обработку персональных данных. Клиент блокирует обычную отправку без согласия и не отправляет email до отметки, однако самостоятельную запись доказательства принятия согласия этот API не сохраняет. При необходимости такой записи серверу нужно принимать и сохранять отдельные реквизиты согласия. Серверные файлы в рамках этой проверки не менялись.

Зарегистрирован ли оператор в реестре, где физически хранятся данные и как настроены журналы рабочего сервера, по клиентскому коду не устанавливалось.
