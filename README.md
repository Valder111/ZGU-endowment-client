# Эндаумент-фонд ЗГУ

Статический сайт Заполярного государственного университета имени Н. М. Федоровского. Переработан из HTML/CSS/JavaScript в React + TypeScript с сохранением исходного дизайна, текстов и всех 44 адресов.

## Стек

- React 19 и TypeScript в строгом режиме.
- Vite с `@vitejs/plugin-react-swc`.
- Tailwind CSS 4 через `@tailwindcss/vite`.
- shadcn/ui: локальные компоненты, `components.json`, генератор `npm run ui:add -- <component>`.
- GSAP и ScrollTrigger как npm-зависимости с очисткой эффектов в React.
- ESLint, Prettier, Playwright и axe-core.

## Запуск

Требуется Node.js 22.12+; для CI выбран Node.js 24.

```sh
npm ci
npm run dev
```

Адрес разработки: http://127.0.0.1:5173.

```sh
npm run build
npm run preview
```

Сборка создаёт `dist/`: готовые HTML-файлы всех страниц, локальные изображения, шрифты и JS/CSS с хешами. Для публикации нужно содержимое `dist/`, исходный `index.html` без сборки не предназначен для хостинга.

## Архитектура

```text
src/
├── api/                        # резерв для согласованного API
├── assets/
│   ├── fonts/                  # локальные шрифты
│   ├── images/
│   ├── styles/
│   └── svg/
├── components/
│   ├── dialogs/                # диалог пожертвования
│   ├── elements/               # шапка, подвал, секции и карточки
│   └── ui/
│       └── formik/             # резерв для адаптеров реальных форм
├── configs/
├── constants/                  # данные проектов, новостей, FAQ и меню
├── context/                    # состояние диалога и увеличенного текста
├── hooks/
│   └── requests/
│       ├── mutations/
│       └── queries/
├── lib/                        # cn для shadcn/ui
├── routes/                     # реестр URL и компоненты страниц
├── types/
├── utils/
├── App.tsx
├── main.tsx                    # гидратация в браузере
└── entry-server.tsx            # рендер HTML при сборке
```

Сайт использует обычные ссылки и отдельный HTML для каждого URL. Это сохраняет прямое открытие и перезагрузку вложенных страниц на статическом хостинге. Содержимое и навигация доступны без JavaScript; диалог, мобильное меню и увеличенный текст требуют JavaScript. Неизвестные адреса показывают страницу 404. В реестре сохранены также исторические адреса `/new/.../` и `/project/all-projects/.../`, включая регистр букв.

Компоненты содержат JSX, без вставки HTML через `dangerouslySetInnerHTML`. Статические данные типизированы и хранятся отдельно от отображения. Реальный серверный API и формы отсутствуют, поэтому запросы, Formik и платёжные интеграции не имитируются.

## Дизайн и интерактивность

Сохранены палитра, композиция, тексты, адаптивные состояния, изображения, локальные шрифты и GSAP-анимации исходного сайта. Для читаемости немного усилен контраст нумерации секций, второстепенного текста и оранжевой карточки. Tailwind отвечает за утилиты и общие стили; особенности макета оформлены в слое `components`, чтобы генератор shadcn мог безопасно добавлять компоненты.

Диалог поддерживает закрытие по Escape, кнопке и фону, удерживает фокус внутри и возвращает его на кнопку открытия. Мобильное меню поддерживает Escape. Настройка увеличенного текста сохраняется локально; при недоступном хранилище работает в пределах страницы. Анимации учитывают `prefers-reduced-motion` и отключаются в режиме увеличенного текста.

## Изменение контента

- URL, заголовки и типы страниц: `src/routes/registry.ts`.
- Направления поддержки: `src/constants/projects.ts`.
- Новости: `src/constants/news.ts`.
- Вопросы и ответы: `src/constants/faq.ts`.
- Меню: `src/constants/navigation.ts`.
- Контакты и название: `src/configs/site.ts`.

При добавлении новой страницы внесите её в реестр. Сборка автоматически создаст соответствующий HTML. При изменении согласованного текста обновите эталоны в `tests/fixtures/original-pages.json` и тесты по смыслу.

## Проверки

```sh
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run test:e2e
# lint + build + браузерные проверки:
npm run check
```

По умолчанию браузерные тесты используют установленный Google Chrome. Для Chromium Playwright:

```sh
npx playwright install chromium
```

Затем установите переменную `PLAYWRIGHT_CHANNEL=chromium` перед `npm run test:e2e`. В PowerShell: `$env:PLAYWRIGHT_CHANNEL = 'chromium'`. CI устанавливает Chromium самостоятельно.

Проверки покрывают все 44 адреса и исходные тексты, HTML без JavaScript, вложенные адреса и перезагрузку, локальные ресурсы, внутренние ссылки, диалог и фокус, мобильное меню, FAQ, сохранение настройки текста, ширины 360–1440 px, аудит axe и запуск анимаций. Автоматические проверки не заменяют приёмку содержания и доступности заказчиком.

## Размещение

По умолчанию базовый путь — `/`, что подходит для `https://<user>.github.io/` и собственного домена. Для сайта проекта скопируйте `.env.example` в `.env` и задайте `BASE_PATH=/repository/` до сборки. Путь должен начинаться и заканчиваться `/`.

Публикуйте только содержимое `dist/`. Для GitHub Pages подготовлен workflow `.github/workflows/deploy.yml`, запускаемый **только вручную**:

1. После своей отправки изменений выберите в Settings → Pages источник **GitHub Actions**.
2. Для сайта в подпапке задайте переменную репозитория `BASE_PATH=/repository/` в Settings → Secrets and variables → Actions → Variables. Для корня домена переменная не нужна.
3. Откройте Actions → Deploy website → Run workflow.

Workflow устанавливает зависимости, проверяет форматирование, линтер, сборку и браузерные тесты, затем публикует `dist/`. `.github/workflows/ci.yml` выполняет только проверки при push и pull request. Во время рефакторинга workflows не запускались и публикация не выполнялась.

Сборка добавляет `.nojekyll` и `404.html`; rewrite всех URL на главную не требуется. Официальная инструкция по размещению: [Vite — GitHub Pages](https://vite.dev/guide/static-deploy#github-pages).

## Что требует отдельного согласования

Исходник обозначен как концепция: сохранены `noindex,nofollow`, пометка «ПРОЕКТ САЙТА», заглушка пожертвования и незаполненные разделы документов/отчётности. Приём платежей не подключён. Перед публичным запуском заказчику необходимо утвердить материалы, реквизиты, документы, условия участия и решение об индексации. Эти данные не подменялись вымышленными.

Проект перенесён в репозиторий `ZGU-endowment-client`. Существующие Git-история и `origin` сохранены. Стартовый шаблон репозитория помещён в локальный архив `.migration/target-template-before-transfer-*`. Коммиты и отправка изменений не выполнялись.

Подробные результаты локальной проверки: [docs/VERIFICATION.md](docs/VERIFICATION.md).
