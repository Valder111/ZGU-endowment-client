`generated/` содержит Axios-клиенты из Swagger. `staff.ts` настраивает URL, cookie и обработку ответов, а `staff-content.ts` связывает типизированные методы с разделами редакции. Публичная выдача запрашивает опубликованные записи без cookie. Настройка адреса API описана в корневом README.

`payments.ts` подключает реальный checkout из серверной ветки `payment-system` и публичный баланс `current_amount` общего проекта. `project-adjustments.ts` читает ручные пополнения и баланс из нового коммита `d27dfa5` ветки `origin/main`; методы изменения доступны администратору в редакторе проекта. `payment-analytics.ts` собирает статистику онлайн-операций из закрытых списков платежей, пожертвований и возвратов. Ограничения API и настройки описаны в [контракте подключения](../../docs/payment-api.md), воспроизводимая генерация обеих спецификаций — в [CODEGEN.md](../../docs/CODEGEN.md).
